# Our Little Universe ❤️  (romantic birthday website)

1. Put your photos in `images/` named `photo1.jpg` ... `photo12.jpg` (.jpeg/.png/.webp also work).
   Empty slots show a soft "your photo goes here" frame; the slideshow, memory wall and collage only use photos you added.
2. Open `index.html`. Tapping the envelope starts the music (`music/one.mpeg`) and the story.
3. Edit names, letter, captions, quiz, "Open when" letters in `js/script.js` (CONFIG at the top).
